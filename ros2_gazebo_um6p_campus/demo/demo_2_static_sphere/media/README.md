# Media provenance

`videos/` preserves the user-supplied MP4 bytes without editing or transcoding. `PROVENANCE.json` records size and SHA-256. These are user recordings, distinct from agent-run verification evidence. Do not infer an exact software revision or scientific safety certification from a video alone.

`screenshots/` contains actual Gazebo captures from documented checks. Captions and source result paths are recorded after verification. No generated concept image is used as execution evidence.
